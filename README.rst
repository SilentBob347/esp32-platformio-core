pioarduino Core (independent fork of PlatformIO)
=================================================

**pioarduino** is an independent fork of `PlatformIO Core <https://github.com/pioarduino/platformio-core>`_.
It does **not** require or use the PlatformIO Registry.

Unlock the true potential of embedded software development with
a collaborative ecosystem, embracing declarative principles,
test-driven methodologies, and modern toolchains for unrivaled success.

* Open source, maximum permissive Apache 2.0 license
* Cross-platform IDE and Unified Debugger
* Static Code Analyzer and Remote Unit Testing
* Multi-platform and Multi-architecture Build System
* Firmware File Explorer and Memory Inspection
